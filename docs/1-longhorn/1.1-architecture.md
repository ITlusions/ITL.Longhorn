# 1.1 Architecture

## What this chart is

`itl.longhorn` is a thin wrapper around the upstream [`longhorn/longhorn`](https://charts.longhorn.io) chart (pinned at `1.13.0` in `itl.longhorn/Chart.yaml`), following the same wrapper-chart pattern as [`ITL.Traefik`](https://github.com/ITlusions/ITL.Traefik), [`ITL.Cilium`](https://github.com/ITlusions/ITL.Cilium), and [`ITL.Tetragon`](https://github.com/ITlusions/ITL.Tetragon): a `dependencies:` entry on the real upstream chart, plus cluster-specific overrides and extra templates layered on top.

On top of the upstream chart, this adds:

- **`templates/namespace.yaml`** — the `longhorn-system` namespace, pre-labeled for privileged Pod Security Admission (see [1.2 Deployment](1.2-deployment.md))
- **`templates/storageclasses/`** — eight `StorageClass` manifests covering every workload tier used across the cluster (see [1.3 Storage classes](1.3-storage-classes.md))
- **`templates/ui-ingress.yaml`** — an IP-allowlisted Ingress for the Longhorn UI (see [1.4 UI access](1.4-ui-access.md))
- **`values.yaml`** — the Talos-specific data-path override described below

## Talos prerequisites

Longhorn's CSI driver and engine need two Talos system extensions on every node:

- `iscsi-tools`
- `util-linux-tools`

Both are already part of the cluster's factory schematic — see `ITL.K8s/scripts/cluster/deploy.env.example` for where that's configured. Without them, Longhorn's engine pods fail to attach volumes.

## Why there's no dedicated disk

Longhorn is normally pointed at a disk dedicated to it — on Talos v1.10+, the recommended approach is a `UserVolumeConfig`-provisioned disk. This cluster's hardware has a single disk per node (see `docs/1-cluster/1.1-architecture.md` in `ITL.K8s`), so there's no second disk to dedicate.

Instead, `values.yaml` sets:

```yaml
longhorn:
  defaultSettings:
    defaultDataPath: /var/lib/longhorn
```

which uses the classic data path on the existing system disk, inside the ephemeral partition. This is a deliberate trade-off, not an oversight — revisit it if any node ever gets a second disk.
